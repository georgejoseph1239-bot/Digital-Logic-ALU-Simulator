# Digital Logic & 4-Bit ALU Simulator

An interactive digital electronics simulator built in C to demonstrate fundamental combinational and sequential logic concepts.

## Features

- Logic Gates — AND, OR, NOT, NAND, NOR, XOR, XNOR
- Automatic Truth Table Generator
- SR, D, JK and T Flip-Flops
- JK Flip-Flop Clock Simulator
- 4-Bit Binary Counter
- 4-Bit ALU
  - Addition
  - Subtraction
  - AND
  - OR
  - XOR
  - NOT

## Technologies

- C
- HTML
- CSS
- JavaScript
- Git & GitHub

## Purpose

This project combines digital electronics concepts with software programming to provide an interactive way to understand digital logic systems.
